# 🇹🇭 Thai Banknote Detection with YOLOv8

This project detects Thai Baht banknotes (20, 50, 100, 500, 1000 Baht) using the YOLOv8 object detection model.  
Dataset annotations are created using **LabelImg** in YOLO format.

---

## 📌 Features

- Detects **5 types of Thai banknotes**
- Uses **Ultralytics YOLOv8** for training and inference
- Dataset labeling performed with **LabelImg** (YOLO format)

---

## 🏷️ Dataset Labeling with LabelImg

To prepare the training dataset, all Thai banknote images were manually annotated using **LabelImg**.
